LoRA 与 QLoRA: 从低秩更新到 4-bit 微调

Created2026-11-02|Updated2026-11-03|notes
|Post Views:

对于一个 4096×40964096 \times 40964096×4096 的线性层, 全参数微调需要更新 16,777,21616,777,21616,777,216 个权重. 如果用 rank 为 888 的 LoRA, 这个线性层只需要训练 65,53665,53665,536 个新增参数, 约为原权重数量的 0.39%0.39\%0.39%.

但原来的大矩阵仍然要放在显存里. QLoRA 进一步把冻结的基座权重量化存储, 再训练高精度的 LoRA 参数. 这页笔记沿着三个问题展开: 更新量为什么可以低秩表示, NF4 的 16 个数值如何分布, 双重量化又在压缩什么.

1. LoRA: 保留基座权重, 学习低秩更新

LoRA 的全称是 Low-Rank Adaptation. 考虑一个省略 bias 的线性层:

y=W0x,W0∈Rdout×din.y = W_0x, \qquad W_0 \in \mathbb{R}^{d_{\mathrm{out}} \times d_{\mathrm{in}}}. y=W0​x,W0​∈Rdout​×din​.

全参数微调直接更新 W0W_0W0​. 如果把训练后的权重写成 W0+ΔWW_0 + \Delta WW0​+ΔW, 那么 ΔW\Delta WΔW 也是一个 dout×dind_{\mathrm{out}} \times d_{\mathrm{in}}dout​×din​ 的矩阵.

LoRA 将更新量参数化为两个小矩阵的乘积:

ΔW=sBA,\Delta W = sBA, ΔW=sBA,

其中

A∈Rr×din,B∈Rdout×r,r≪min⁡(din,dout).A \in \mathbb{R}^{r \times d_{\mathrm{in}}}, \qquad B \in \mathbb{R}^{d_{\mathrm{out}} \times r}, \qquad r \ll \min(d_{\mathrm{in}}, d_{\mathrm{out}}). A∈Rr×din​,B∈Rdout​×r,r≪min(din​,dout​).

sss 是缩放系数, 原始 LoRA 使用 s=α/rs = \alpha/rs=α/r. 训练时冻结 W0W_0W0​, 只更新 AAA 和 BBB. 因此前向计算变为:

y=(W0+sBA)x=W0x+sB(Ax).y = (W_0 + sBA)x = W_0x + sB(Ax). y=(W0​+sBA)x=W0​x+sB(Ax).

这个参数化和缩放方式来自 LoRA 论文 Section 4.1.

从维度理解两条计算路径

采用列向量约定, 输入 x∈Rdinx \in \mathbb{R}^{d_{\mathrm{in}}}x∈Rdin​. 两条路径分别是:

路径 计算 输出维度 训练时更新谁
基座路径 x↦W0xx \mapsto W_0xx↦W0​x doutd_{\mathrm{out}}dout​ 冻结 W0W_0W0​
LoRA 路径 x↦Ax↦B(Ax)x \mapsto Ax \mapsto B(Ax)x↦Ax↦B(Ax) din→r→doutd_{\mathrm{in}} \to r \to d_{\mathrm{out}}din​→r→dout​ 更新 A,BA, BA,B

两条路径的输出维度相同, 因此可以逐元素相加. 实际执行时可以先算 AxAxAx, 再算 B(Ax)B(Ax)B(Ax), 无需在每次前向时构造完整的 BABABA.

如果一次处理一段序列, 令每个 token 是 XXX 的一列:

X∈Rdin×L,AX∈Rr×L,Y=W0X+sB(AX).X \in \mathbb{R}^{d_{\mathrm{in}} \times L}, \qquad AX \in \mathbb{R}^{r \times L}, \qquad Y = W_0X + sB(AX). X∈Rdin​×L,AX∈Rr×L,Y=W0​X+sB(AX).

这里的 LLL 是 token 数. 很多框架把 token 放在行上, 会把公式写成转置后的形式; 只要统一约定, 数学含义相同.

参数到底减少了多少

对这一个线性层, 两种方式的可训练参数量分别为:

Nfull=doutdin,NLoRA=r(din+dout).N_{\mathrm{full}} = d_{\mathrm{out}}d_{\mathrm{in}}, \qquad N_{\mathrm{LoRA}} = r(d_{\mathrm{in}} + d_{\mathrm{out}}). Nfull​=dout​din​,NLoRA​=r(din​+dout​).

当 din=dout=dd_{\mathrm{in}} = d_{\mathrm{out}} = ddin​=dout​=d 时, 比例为:

NLoRANfull=2rd.\frac{N_{\mathrm{LoRA}}}{N_{\mathrm{full}}} = \frac{2r}{d}. Nfull​NLoRA​​=d2r​.

代入开头的 d=4096,r=8d = 4096, r = 8d=4096,r=8, 得到 16/4096=0.0039062516/4096 = 0.0039062516/4096=0.00390625. 这是单个线性层的参数比例, 不能直接当作整个模型的显存比例.

2. 为什么更新量的 rank 不超过 r

手写笔记里最关键的不等式是:

rank⁡(BA)≤min⁡{rank⁡(A),rank⁡(B)}≤r.\operatorname{rank}(BA) \leq \min\{\operatorname{rank}(A), \operatorname{rank}(B)\} \leq r. rank(BA)≤min{rank(A),rank(B)}≤r.

先看 rank⁡(BA)≤rank⁡(B)\operatorname{rank}(BA) \leq \operatorname{rank}(B)rank(BA)≤rank(B). 把 AAA 按列展开:

A=[a1,a2,…,adin],BA=[Ba1,Ba2,…,Badin].A = [a_1, a_2, \ldots, a_{d_{\mathrm{in}}}], \qquad BA = [Ba_1, Ba_2, \ldots, Ba_{d_{\mathrm{in}}}]. A=[a1​,a2​,…,adin​​],BA=[Ba1​,Ba2​,…,Badin​​].

每个 BaiBa_iBai​ 都是 BBB 的列向量的线性组合. 因此 BABABA 的列空间包含在 BBB 的列空间中, 维度不会超过 rank⁡(B)\operatorname{rank}(B)rank(B).

另一边, 把矩阵乘法看成线性映射的复合:

Rdin→ARr→BRdout.\mathbb{R}^{d_{\mathrm{in}}} \xrightarrow{A} \mathbb{R}^{r} \xrightarrow{B} \mathbb{R}^{d_{\mathrm{out}}}. Rdin​A​RrB​Rdout​.

AAA 的像空间只有 rank⁡(A)\operatorname{rank}(A)rank(A) 维. 再经过线性映射 BBB, 维度也不会增加, 所以 rank⁡(BA)≤rank⁡(A)\operatorname{rank}(BA) \leq \operatorname{rank}(A)rank(BA)≤rank(A).

乘上标量 sss 不会增加秩, 所以 rank⁡(ΔW)≤r\operatorname{rank}(\Delta W) \leq rrank(ΔW)≤r. 被限制为低秩的是更新量 ΔW\Delta WΔW, 而 W0+ΔWW_0 + \Delta WW0​+ΔW 仍然可以满秩.

这个证明只说明参数化的性质. 一个具体任务能否用很小的 rrr 达到足够好的效果, 仍然要靠实验判断.

3. LoRA 的训练与使用

原始 LoRA 将 AAA 随机初始化, 将 BBB 初始化为零. 这样训练开始时 BA=0BA = 0BA=0, 新模型的输出与基座相同. 两个矩阵不能同时初始化为零, 否则在这个双线性参数化下, 两边的梯度都会是零. 初始化方式见 LoRA 论文.

以风格化图像生成为例, 可以在一个支持 LoRA 的基座上, 用目标风格的数据训练一组 A,BA, BA,B. 保存和切换这组 adapter, 就能复用同一份基座. 具体学到什么, 仍取决于数据, 训练目标和选择适配的模块.

训练后有两种使用方式:

  • 保留独立的 A,BA, BA,B, 按需加载或切换 adapter.
  • 在高精度权重中合并 Wmerged=W0+sBAW_{\mathrm{merged}} = W_0 + sBAWmerged​=W0​+sBA, 之后执行普通线性层.

合并可以消除独立 LoRA 分支的推理计算, 但未合并的 LoRA 仍然有额外运算. 原论文关于推理延迟的讨论基于权重可以合并这一点. 来源: LoRA Section 4.1.

冻结基座还意味着无需为这些权重保存训练用的梯度和 Adam 状态. 不过, 为了训练前面层里的 adapter, 梯度仍然需要反向通过冻结的层, 传回前面的 adapter. 冻结参数不等于可以把整条基座路径放进 no_grad().

4. QLoRA: 区分存储精度与计算精度

LoRA 减少了可训练参数, 基座权重的存储仍然很大. QLoRA 在这一步继续压缩: 冻结的基座使用 4-bit 存储, 运算时反量化到计算所用的类型, 再与 LoRA 分支相加. 原论文主要使用 BF16 计算. 来源: QLoRA Section 3.

将量化后的基座记为 W4bitW_{\mathrm{4bit}}W4bit​, 可以写成:

W^0=dequant⁡(W4bit,quantization metadata),\widehat W_0 = \operatorname{dequant}(W_{\mathrm{4bit}}, \text{quantization metadata}), W0​=dequant(W4bit​,quantization metadata),

Y=W^0X+sB(AX).Y = \widehat W_0X + sB(AX). Y=W0​X+sB(AX).

W^0\widehat W_0W0​ 是原权重的近似值. 4-bit 表示和量化元数据保持冻结, 优化器更新的是 LoRA 参数. 反量化也不意味着必须在整个训练期间常驻一份完整的 BF16 基座副本.

原始 QLoRA 的三个组成部分各自解决不同的问题:

机制 作用对象 目的
NF4 基座权重 用 4-bit 非均匀码本存储权重
Double Quantization 量化所需的缩放常数 减少量化元数据的存储
Paged Optimizers 优化器状态 在显存压力下通过 CPU/GPU 分页缓解峰值

手写笔记主要讨论前两项. Paged Optimizers 使用统一内存机制, 可能产生 CPU/GPU 数据迁移, 不能把它理解成免费增加显存. 来源: QLoRA Section 3.

5. NF4: 16 个值应该放在哪里

4-bit 可以编码 24=162^4 = 1624=16 种状态. NF4 中, 每种状态对应一个查表得到的数值. 它没有普通浮点数那样的符号位, 指数位和尾数位划分.

如果权重在零附近更密集, 那么在零附近放更多表示值, 通常比在整个区间里均匀分配更合适. NF4 使用零中心正态分布作为设计码本的参考, 这是一种分布假设, 不要求每层的真实权重都严格服从同一个高斯分布.

从 CDF 到分位数

令 Z∼N(0,1)Z \sim \mathcal{N}(0, 1)Z∼N(0,1), 其累积分布函数为 FZF_ZFZ​, 分位数函数为:

QZ(p)=FZ−1(p),0<p<1.Q_Z(p) = F_Z^{-1}(p), \qquad 0 < p < 1. QZ​(p)=FZ−1​(p),0<p<1.

若 W=σZW = \sigma ZW=σZ 且 σ>0\sigma > 0σ>0, 则 QW(p)=σQZ(p)Q_W(p) = \sigma Q_Z(p)QW​(p)=σQZ​(p).

分位数函数回答的是: 给定累计概率 ppp, 对应的随机变量取值是多少. 如果在概率轴上等间距取点, 映射到数值轴后, 点在零附近更密, 在两端更疏. 这是因为:

dQZ(p)dp=1fZ(QZ(p)).\frac{\mathrm{d}Q_Z(p)}{\mathrm{d}p} = \frac{1}{f_Z(Q_Z(p))}. dpdQZ​(p)​=fZ​(QZ​(p))1​.

零附近的概率密度 fZf_ZfZ​ 大, 相同的概率增量对应更短的数值区间.

为了单独理解这个思路, 可以构造 16 个有限的分位数样点:

q~i=QZ ⁣(i+1/216),i=0,…,15.\widetilde q_i = Q_Z\!\left(\frac{i + 1/2}{16}\right), \qquad i = 0, \ldots, 15. q​i​=QZ​(16i+1/2​),i=0,…,15.

这里取的是每段概率区间的中点, 避开了 QZ(0)=−∞Q_Z(0) = -\inftyQZ​(0)=−∞ 和 QZ(1)=+∞Q_Z(1) = +\inftyQZ​(1)=+∞. 这只是一个说明分位数采样的例子, 并非实际 NF4 的码本生成公式; 它也没有精确的零.

手写笔记里对端点的疑问

QLoRA 论文 Equation (4) 写成:

qi=12[QZ ⁣(i2k+1)+QZ ⁣(i+12k+1)].q_i = \frac{1}{2}\left[ Q_Z\!\left(\frac{i}{2^k + 1}\right) + Q_Z\!\left(\frac{i + 1}{2^k + 1}\right) \right]. qi​=21​[QZ​(2k+1i​)+QZ​(2k+1i+1​)].

这个式子是在数值空间对两个分位数取平均, 不是直接对概率取平均. 因为 QZQ_ZQZ​ 非线性, 一般有:

QZ(p1)+QZ(p2)2≠QZ ⁣(p1+p22).\frac{Q_Z(p_1) + Q_Z(p_2)}{2} \neq Q_Z\!\left(\frac{p_1 + p_2}{2}\right). 2QZ​(p1​)+QZ​(p2​)​​=QZ​(2p1​+p2​​).

阅读时还需要明确索引和端点约定. 仅把分母换成 2k+12^k + 12k+1, 并不能自动避免所有无穷端点: 若 i=0i = 0i=0, 第一项仍然是 QZ(0)Q_Z(0)QZ​(0); 若连续取 i=1,…,2ki = 1, \ldots, 2^ki=1,…,2k, 最后一项又会遇到 QZ(1)Q_Z(1)QZ​(1). 所以不能只凭这一行公式就直接复现 NF4, 还需要结合实际码本构造. 论文公式与说明.

实际 NF4 包含一个精确的零

如果码本完全正负对称, 又要包含零, 那么数值总数就是奇数. NF4 需要 16 个不同的表示值, 因而采用略不对称的分配: 7 个负值, 1 个零, 8 个正值.

在 bitsandbytes 的 create_normal_map 中, 正负两侧使用不同数量的有限分位数采样点, 合入零后再归一化. NF4 码本的近似值如下:

编号 数值 编号 数值
0 -1.000000 8 0.079580
1 -0.696193 9 0.160930
2 -0.525073 10 0.246112
3 -0.394917 11 0.337915
4 -0.284441 12 0.440710
5 -0.184773 13 0.562617
6 -0.091050 14 0.722957
7 0.000000 15 1.000000

精确表示零, 可以让 padding 或本来就是零的权重在量化后继续为零. 但这并不意味着 QLoRA 会自动产生稀疏权重, 或自动获得稀疏计算加速.

分位数思路解释了码本为什么在零附近更密. 实际 NF4 还包含截断, 精确零和块归一化等设计, 不宜把直觉上的等概率分箱当作每个真实权重块都严格满足的性质.

6. 分块量化: 4-bit 编号之外还要保存 scale

设一个权重块为 wjw_jwj​, 其缩放常数为:

aj=max⁡i∣wj,i∣.a_j = \max_i |w_{j,i}|. aj​=imax​∣wj,i​∣.

当 aj>0a_j > 0aj​>0 时, 先归一化:

uj,i=wj,iaj∈[−1,1].u_{j,i} = \frac{w_{j,i}}{a_j} \in [-1, 1]. uj,i​=aj​wj,i​​∈[−1,1].

设 NF4 码本为 {c0,…,c15}\{c_0, \ldots, c_{15}\}{c0​,…,c15​}, 为归一化后的值选择最近的码本项:

zj,i=arg min⁡t∈{0,…,15}∣uj,i−ct∣,w^j,i=ajczj,i.z_{j,i} = \operatorname*{arg\,min}_{t \in \{0, \ldots, 15\}} |u_{j,i} - c_t|, \qquad \widehat w_{j,i} = a_j c_{z_{j,i}}. zj,i​=t∈{0,…,15}argmin​∣uj,i​−ct​∣,wj,i​=aj​czj,i​​.

若整个块都是零, 则可以直接表示为零, 避免除以零.

因此, 保存下来的内容包括每个权重的 4-bit 编号 和每个块的 scale. 编号不是原权重本身, 解码时还需要共享的码本和该块的 scale.

采用论文分析中的 block size 646464, 若每块的 scale 用 FP32 保存, 平均每个权重的开销为:

4+3264=4.5bit/param.4 + \frac{32}{64} = 4.5 \quad \text{bit/param}. 4+6432​=4.5bit/param.

4-bit 权重并不等于平均存储恰好只有 4 bit. scale 的开销正是双重量化要继续压缩的部分. 来源: QLoRA 的分块量化与 DQ 分析.

7. Double Quantization: 再量化一次 scale

第一层量化得到很多 aja_jaj​. Double Quantization 将这些 scale 当成一组新的数据, 再做一次量化.

先减去均值 μ\muμ, 再对中心化后的 scale 分块. 若第二层某个块的缩放常数为 bgb_gbg​, 就可以将重建过程概括为:

a^j=μ+bg(j)r^j,\widehat a_j = \mu + b_{g(j)}\widehat r_j, aj​=μ+bg(j)​rj​,

其中 g(j)g(j)g(j) 表示 aja_jaj​ 属于哪个第二层块, r^j\widehat r_jrj​ 是通过 8-bit 量化表示重建出的归一化值. 最终权重近似为:

w^j,i=a^jczj,i.\widehat w_{j,i} = \widehat a_j c_{z_{j,i}}. wj,i​=aj​czj,i​​.

这里的 8-bit 用在 scale 上, NF4 的 4-bit 用在权重上. 两层量化的对象不同. bitsandbytes 的实现 对应先计算 scale 的均值, 再调用 quantize_blockwise 压缩中心化后的 scale.

4.127 bit/param 从哪里来

沿用论文的计算口径:

  • 每 646464 个原始权重共享一个第一层 scale.
  • 每个第一层 scale 量化后占 888 bit.
  • 每 256256256 个第一层 scale 共享一个 FP32 的第二层 scale.

于是, 平均每个原始权重分摊的 scale 开销为:

864+3264×256=0.125+0.001953125=0.126953125bit/param.\frac{8}{64} + \frac{32}{64 \times 256} = 0.125 + 0.001953125 = 0.126953125 \quad \text{bit/param}. 648​+64×25632​=0.125+0.001953125=0.126953125bit/param.

加上权重本身的 4-bit 编号:

4+0.126953125≈4.127bit/param.\boxed{4 + 0.126953125 \approx 4.127 \quad \text{bit/param}.} 4+0.126953125≈4.127bit/param.​

相对于 4.54.54.5 bit/param, 进一步节省约 0.3730.3730.373 bit/param. 以上按大张量摊销, 忽略均值, 码本和其他少量元数据; block size 或数据类型改变时, 数字也会变化. 来源: QLoRA 的 Double Quantization 分析.

4.127 bit/param 描述的是被这样量化的基座权重及其 scale 的近似存储成本. 总训练显存还包括 LoRA 参数与梯度, 优化器状态, 激活值, 临时缓冲区, 以及没有被量化的模块.

8. 把几个容易混淆的概念分开

问题 对应的概念
哪些参数接受优化器更新 LoRA 冻结基座, 训练低秩分支
冻结的基座以什么格式保存 QLoRA 使用低比特量化存储
4-bit 能表示哪些归一化值 NF4 的非均匀码本
每个块的 scale 如何压缩 Double Quantization
如何缓解优化器状态造成的显存压力 Paged Optimizers

手写笔记还联想到 DeepSeek 的 MLA. 两者都有先进入低维空间的直觉, 但对象不同: LoRA 参数化的是任务适配的权重更新量, MLA 压缩的是 attention 中的表示, 包括用于减少 KV cache 的联合潜在表示. 因而不能把 MLA 直接当作 LoRA 的使用方式. MLA 的定义见 DeepSeek-V2 Section 2.1.

实际估算资源时, 可以先算 r(din+dout)r(d_{\mathrm{in}} + d_{\mathrm{out}})r(din​+dout​) 确认可训练参数量, 再按量化块大小和元数据格式计算基座存储, 最后单独测量激活值与运行时峰值. 这三步回答的是不同的问题.
