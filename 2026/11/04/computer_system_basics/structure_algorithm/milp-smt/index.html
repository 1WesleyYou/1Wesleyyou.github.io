MILP 与 SMT

Created2026-11-04|Updated2026-11-05|notes
|Post Views:

MILP

  • LP (Linear Programming): 线性规划, 变量连续取值.
  • IP (Integer Programming): 整数规划. 全部变量为 0-1 时, 是其中的 0-1 IP.
  • MILP (Mixed-Integer Linear Programming): 混合整数线性规划, 可以同时包含整数变量和连续变量.

找到好解与证明最优

以最小化问题为例:

  • Incumbent (UB): 目前找到的最好方案, 其目标值提供上界. 例如 OPT≤10\mathrm{OPT}\leq 10OPT≤10.
  • Best Bound (LB): 已经证明的下界. 例如 OPT≥8\mathrm{OPT}\geq 8OPT≥8.
  • Optimality Gap: 目前未消除的最优性不确定范围. 这里的绝对 gap 为 UB−LB=2UB-LB=2UB−LB=2.

找到好解和证明它最优, 是两件事.

LP Relaxation 与剪枝

LP Relaxation: 去掉整数限制, 同时保留原目标和其余约束. 例如将 x∈{0,1}x\in\{0,1\}x∈{0,1} 放松为 0≤x≤10\leq x\leq 10≤x≤1.

可行域扩大, 因而对最小化问题可以提供下界:

OPTLP≤OPTIP.\mathrm{OPT}_{\mathrm{LP}}\leq\mathrm{OPT}_{\mathrm{IP}}. OPTLP​≤OPTIP​.

求解器 Pruning: 若某个 branch 的下界已经不小于 incumbent 的目标值 UBUBUB, 就不能找到更好的解, 可以剪枝.

Big-M 理论

用足够大的 MMM, 让某条约束在不需要时自动失效.

例如, 两个操作不能重叠, 开始时间为 s1,s2s_1,s_2s1​,s2​, 持续时间为 d1,d2d_1,d_2d1​,d2​:

  • MMM 太小: 可能删掉合法解.
  • MMM 太大: LP 松弛可能变弱, 影响求解效率, 也可能带来数值问题.

固定 HHH 时是在求可行解. 枚举 HHH, 就可以把这个可行性问题用于搜索最少时间步数; 要证明最优, 需要证明更小的 HHH 都不可行.

SAT

SAT: 求 Boolean 表达式是否存在满足的赋值.

CNF (Conjunctive Normal Form): 若干 clause 之间用 AND 连接, 每个 clause 内部用 OR 连接 literal.

Unit propagation: 在当前赋值下, 若一个 clause 只剩一个未定 literal, 其余 literal 都为 false, 就必须让这个 literal 为 true. 继续传播这些必然的赋值, 可以缩小搜索空间.

SMT

SMT (Satisfiability Modulo Theories): 在 Boolean 结构之外, 还检查整数, 实数等理论约束是否可以同时满足.

用 SMT 处理优化问题

  1. Bounded Search: 设置搜索边界, 用 SAT/SMT 求解不同配置的可行性, 再调整配置, 缩小搜索范围. 前面枚举 HHH 就是一个例子.
  2. OMT (Optimization Modulo Theories): 在 SMT 约束上直接加入优化目标.

回顾 P 与 NP

  • P: 可以在多项式时间内求解的决策问题.
  • NP: 对于答案为 yes 的实例, 存在多项式长度的证书, 可以在多项式时间内验证.
  • P⊆NPP\subseteq NPP⊆NP: 如果已经能在多项式时间内求解, 验证时可以直接运行求解算法.

对问题 LLL, xxx 表示它的一个具体 instance, ccc 表示 certificate. NP 的验证关系可以写成:

x∈L⟺∃c: VL(x,c)=1,x\in L\quad\Longleftrightarrow\quad\exists c:\ V_L(x,c)=1, x∈L⟺∃c: VL​(x,c)=1,

其中 ccc 的长度以及验证时间都受 ∣x∣|x|∣x∣ 的多项式限制.

3-SAT 既是 NP-hard, 又属于 NP, 因此是 NP-complete 问题.
